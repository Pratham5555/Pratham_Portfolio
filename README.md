# Pratham Maheshwari — Portfolio

Personal portfolio website showcasing my projects, skills, and experience as a Full-Stack Developer and CS undergrad at JIIT Noida.

🔗 **Live Site:** [pratham-portfolio-chi-six.vercel.app](https://pratham-portfolio-chi-six.vercel.app)

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Deployment:** Vercel

---

## Sections

- **Hero** — Introduction and social links
- **About** — Background and education
- **Skills** — Technologies and tools I work with
- **Projects** — Featured work with live demos and source code
- **Contact** — Ways to get in touch

---

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Pratham5555/Pratham_Portfolio.git
cd Pratham_Portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Project Structure

```
src/
├── app/          # Next.js app router (layout, page, globals)
├── components/
│   ├── sections/ # Hero, About, Skills, Projects, Contact
│   ├── layout/   # Navbar, Footer
│   └── ui/       # Reusable UI components
├── data/         # Static content and project data
└── lib/          # Utility functions
```

## Deployment

This site is deployed on **Vercel**. Any push to the `main` branch automatically triggers a new deployment.
